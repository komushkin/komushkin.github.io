# MAX GYM — Павловский Посад

Статический сайт: HTML, CSS и JavaScript. Сборка и установка зависимостей не требуются.

## Просмотр
Откройте index.html в браузере.

## Загрузка на GitHub
Создайте репозиторий и загрузите содержимое этой папки в его корень: index.html, style.css, script.js, README.md и .gitignore.

## GitHub Pages
В настройках репозитория откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку / (root), затем сохраните.

## Внешние ресурсы
Изображения загружаются с maxgym-fitnes.ru, шрифты — из Google Fonts; карта и внешние ссылки требуют интернета. Ссылки на услуги, цены и другие разделы ведут на исходный сайт maxgym-fitnes.ru.

Исходники экспортированы из проекта Sites без изменения дизайна и поведения. Служебная история Git и конфигурация хостинга Sites не включены.

Форма обратного звонка работает в демонстрационном режиме. Для отправки заявок задайте CALLBACK_ENDPOINT в script.js и подключите обработчик на сервере.
